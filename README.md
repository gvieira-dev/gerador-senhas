# Gerador de Senhas

Este projeto é uma página web simples para gerar senhas fortes e seguras em poucos segundos.

## O que ele faz

- Cria senhas aleatórias com tamanho configurável
- Inclui letras minúsculas e números por padrão
- Permite ativar letras maiúsculas e caracteres especiais
- Exibe a senha gerada diretamente na interface
- Possui botão para copiar a senha para a área de transferência
- Ajusta o tema visual entre claro e escuro

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Ajuste o tamanho da senha conforme desejar.
3. Marque as opções desejadas:
   - letras maiúsculas
   - caracteres especiais
4. Clique em "Gerar nova senha".
5. Use o botão "Copiar" para copiar a senha.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivo

O objetivo do projeto é facilitar a criação de senhas fortes para uso pessoal, com uma interface leve e fácil de usar.
